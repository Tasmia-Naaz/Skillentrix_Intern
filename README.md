# Skillentrix_Intern
💳 Credit Card Fraud Detection using AI &amp; ML in Python. Detects fraudulent transactions using Logistic Regression, Random Forest &amp; XGBoost. Handles class imbalance via SMOTE &amp; Isolation Forest. Includes EDA, feature scaling, ROC-AUC evaluation, threshold tuning &amp; an interactive prediction dashboard. Dataset: Kaggle ULB.
